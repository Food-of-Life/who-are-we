# Food of Life

A Next.js site for intimate dining events in Baltimore, featuring the A Night of Flavor tasting and the Made With Care partnership deck.

Run `pnpm install` and `pnpm dev` for local development. Run `pnpm build` to check the production build.

Copy `.env.example` to `.env.local` to set the public sponsor email and phone number. The contact form appears when a Resend API key, verified sender, and recipient are configured. Set `SITE_URL` to the public site origin to enable sitemap entries and indexing.
